# Translations

Developer rules: `vibe-coding-rules/localization.md`.

| File                                    | Purpose                                                            |
| --------------------------------------- | ------------------------------------------------------------------ |
| `bundle.l10n.json`                      | English source, generated by `npm run l10n:extract`. Do not edit   |
| `bundle.l10n.<locale>.json`             | A shipped language. Translates every message                       |
| `drafts/bundle.l10n.<locale>.json`      | A language in progress. Not packaged, may be partial               |

## Translating

1. Copy `bundle.l10n.json` to `drafts/bundle.l10n.<locale>.json`. Use VS Code's locale id: `zh-cn`, `ja`, `es`, `pt-br`, `ru`, `ko`, `fr`, `de`, `zh-tw`, `it`, `pl`, `cs`, `hu`, `tr`.
2. Replace each value with the translation. For an entry written as `{ "message": ..., "comment": ... }`, replace the whole value with the translated text; the comment is a note for you.
3. Keep the key exactly as it is.
4. Keep every `{0}`, `{1}` placeholder. You may move them.
5. Do not add `<` or `>`.
6. Leave out a message you are unsure about. It is shown in English.
7. Open a pull request that changes only files in this folder.
